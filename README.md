# Event Attendance Tracker

Track attendance for individual events or complete calendars in Admidio 5.0.x.
The plugin supports attendance recording, self-excuses, reports and exports.

Requires Admidio 5.0.x and PHP 8.2 or newer.

## Installation

1. Copy or clone the repository to `adm_plugins/event-attendance` in an Admidio 5.0.x installation.
2. Open `adm_plugins/event-attendance/event-attendance-tracker.php` as an administrator and start the installation.
3. Open **Plugin settings** to configure access and the features you want to use.

See [Installation and updates](https://github.com/MightyMCoder/EventAttendanceTracker/wiki/Installation-and-Updates-EN)
for the full instructions.

## Updates and removal

Updates and uninstallation are available in **Plugin settings**.
Back up your database beforehand.
See [Installation and updates](https://github.com/MightyMCoder/EventAttendanceTracker/wiki/Installation-and-Updates-EN),
which also covers uninstallation and the data it removes.

See the [GitHub releases](https://github.com/MightyMCoder/EventAttendanceTracker/releases) for the release history.
