# Changelog

All notable changes to Event Attendance Tracker are documented in this file.

## 1.0.0-beta.1 — 2026-10-14

First public beta release for Admidio 5.0.x.

- Create attendance trackers for selected events or complete calendars.
- Record attendance, self-excuses and cancelled occurrences.
- Provide configurable report periods, filterable reports and CSV, XLSX and PDF exports.
- Support organization-specific settings, role-based access, menu integration and a configurable PDF logo.
- Automate snapshots and absent statuses using the CLI or token-protected web cron endpoint.
- Install, update and uninstall the plugin from its own settings interface.

## Release policy

Beta versions use the form `MAJOR.MINOR.PATCH-beta.N`. Every beta increment is an updateable
plugin version. The first stable release of a version is published without the beta suffix.
